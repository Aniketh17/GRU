Navigation & layout

  • Desktop ≥ 1024 px: 248 px sidebar (Today, Jobs, Applications, Interviews, Review; Your day: Agenda, Notes; Settings) + content up to 1140 px.
  • Tablet 640–1023 px: 72 px icon rail; detail panels open as sheets.
  • Mobile < 640 px: bottom tab bar (Today, Jobs, Applications, Agenda, More) with safe-area padding; list → detail push.
  • Ctrl K jump-to palette on desktop; a Quick add “+” everywhere.

Automatic theme rule

  • Auto (default): light 09:00–18:30, dark otherwise, in Pacific/Auckland via Intl, so DST is automatic.
  • A tiny inline script sets data-theme before first paint, so there’s no flash of the wrong theme.
  • A timer fires at the next boundary, plus a re-check on focus or visibility, so it switches without a refresh.
  • Manual Light or Dark persists until you choose Auto again.
