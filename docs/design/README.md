# GRU design source

Exported from the Claude Design canvas "GRU Interface Design" (approved by Ani, 2026-11-15).
Each `*.dc.html` file is one artboard; `canvas.json` is the board layout. These files are a
**reference for implementation**, not shipped code. They load the canvas runtime (`support.js`)
and Google Fonts for preview only; the real app self-hosts its fonts and loads no third-party
resources (spec section 2).
