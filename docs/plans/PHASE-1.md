# Phase 1: Dashboard. Plan, build and walkthrough

**Approved by Ani on 2026-11-15** ("the design looks amazing … proceed with building it"). The design decisions Ani didn't answer were taken at the recommended defaults (D-043).

## Scope (SPEC §17 Phase 1)
Application CRUD, events timeline, filters, search, manual status (plus undo), PWA shell, navigation. Theme scheduling per Ani's requirement.

## What was built
**Backend (Worker):**
- `GET /api/applications`: status filter (active/closed/single/all), search on normalised company/role with LIKE wildcards escaped, `stale=1`, cursor pagination capped at 50
- `GET /api/applications/summary`: counts by status and the stale count
- `POST /api/applications`, `GET /PATCH /DELETE /api/applications/:id`. Notes are AES-GCM encrypted, bound to the row
- `POST /api/applications/:id/status`: manual override recording `prev_status`
- `GET /api/applications/:id/timeline`, and `POST /api/events/:id/undo` (24-hour window)
- Stale = applied/assessment with no activity for 14 days, computed on read (the scheduler arrives in Phase 3)

**Frontend (React 19, React Router 7, TanStack Query 5, Tailwind 4, self-hosted Inter):**
- App shell: 248 px sidebar on desktop, bottom tab bar on mobile with safe areas. Only shipped sections appear (D-041).
- Today: greeting, pipeline, recent activity, follow-ups due, honest system health, and a zero-data onboarding state.
- Applications: search, status chips, list plus detail (side panel on desktop, full screen on mobile), timeline with Undo, a status selector with Undo toast, encrypted notes, edit/delete dialogs.
- Settings: theme selector (Automatic/Light/Dark) with the live schedule bar, pause switch, sign out, wipe (typed phrase + 10-second hold).
- Locked/wiped page; empty, loading, error and toast states.
- **Theme:**
  - automatic light 09:00–18:30, dark otherwise, in Pacific/Auckland;
  - `theme-init.js` runs before first paint, so there's no flash;
  - a timer at the next boundary (capped at 30 min) plus re-checks on focus, visibility and storage, so it switches without a refresh;
  - manual override persists; the quick toggle cycles Auto → Light → Dark.
- **PWA:**
  - manifest, PNG/SVG icons (generated by `scripts/gen-icons.mjs`), apple-touch-icon, standalone display;
  - the service worker caches only hashed `/assets/*`, never `/api`.

## Bugs found and fixed during the build
- **Select accessible name:** a `<select>` nested in its `<label>` leaked the selected option into the accessible name ("Source Direct / company site"). The label is now a sibling.
- **Hyphen spacing:** global tabular numerals widened Inter's hyphens. Numerals are now tabular only on numbers.
- **Env-file `$` expansion:** wrangler's dotenv-expand mangled `$` in `AUTH_VERIFIER`, even when quoted. It must be escaped as `\$` (D-039).
- **Tautological test:** a `%` search assertion compared the result with itself. It was replaced with real expectations.
